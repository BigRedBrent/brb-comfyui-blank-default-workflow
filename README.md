# Blank Default Workflow

Makes ComfyUI's default workflow blank. ComfyUI opens its default workflow, with Load Checkpoint, KSampler and so on, when you close the last tab, or when it starts with no tabs to restore. With this add-on, you get an empty workflow instead, the same as clicking **+** on the tab bar.

It doesn't change any of ComfyUI's files, so ComfyUI updates don't undo it. Remove the add-on to get the default workflow back.

It works whether your version of ComfyUI's page has the default workflow built in, or asks ComfyUI for it from its `default_workflow.json` file.

## Installing

Install it through a manager, or put this folder in ComfyUI's `custom_nodes` folder, then restart ComfyUI and refresh the browser. It adds no nodes.
